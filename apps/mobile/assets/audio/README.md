# Table sound effects

Six Kenney Casino Audio 1.1 CC0 assets: card-deal.wav, card-reveal.wav, chips-bet.wav, chips-raise.wav, cards-fold.wav, pot-collect.wav. Converted to 44.1kHz mono PCM16. See docs/audio-assets.md and docs/audio-phase3-license-evidence.json for source hashes, original license and edits.

Other WAV files remain original synthesized placeholders from scripts/generate-table-audio.cjs. turn.wav is the my-turn notification, not the turn card. Playback gains and user settings are unchanged.
