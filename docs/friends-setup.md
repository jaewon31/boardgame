# 친구 기능 연결

계정 기능(001_accounts.sql) 다음 단계입니다. 홈의 **친구** 버튼에서 코드 요청, 받은 요청 수락·거절, 보낸 요청 취소, 친구 삭제를 제공합니다.

## Supabase에 적용

1. Supabase SQL Editor에서 **새 쿼리**를 만듭니다.
2. `supabase/migrations/002_friends.sql` 전체를 붙여넣고 실행합니다. 이 파일은 다시 실행해도 기존 친구 관계를 보존합니다. 001 파일은 다시 실행하지 않습니다.
3. 앱을 다시 열고 홈의 **친구**를 선택합니다.
4. 두 사용자가 각각 Google 로그인 후 서로 다른 닉네임을 설정합니다. A가 B의 12자리 친구 코드로 요청하고 B의 받은 요청에서 수락하면 양쪽 친구 목록에 나타납니다.

내 코드는 선택해 복사하거나 공유 창으로 전달할 수 있습니다. 프로필 이메일은 상대에게 노출하지 않습니다. 친구 목록은 화면을 열어둔 동안 10초마다 갱신하고, 직접 새로고침할 수도 있습니다.

## 권한과 제한

- 클라이언트는 친구 테이블을 직접 수정할 수 없습니다. DB 함수가 로그인 사용자와 요청 당사자를 검사합니다.
- 친구가 되어도 상대 프로필 전체를 읽을 수 없습니다. 친구 화면에는 닉네임만 전달합니다.
- 자기 자신에게 요청할 수 없으며, 양방향 중복 요청은 하나로 유지됩니다. 상대가 먼저 요청했다면 직접 수락해야 합니다.
- 친구 200명, 보낸 대기 요청 20개, 하루 신규 요청 30개로 제한합니다.
- 친구 삭제·탈퇴 시 관계가 제거됩니다. 그룹·상대 전적·온라인 상태·방 초대 알림은 다음 단계입니다.

## 검증

PGlite PostgreSQL 엔진 테스트에서 실제 SQL을 실행해 익명 접근, 타인 요청 위조, 직접 테이블 수정, 중복 요청, 수락·거절·취소·삭제와 요청 한도를 검사합니다. 호스팅된 Supabase 프로젝트에서는 SQL 적용 후 두 실제 계정으로 마지막 연결 확인이 필요합니다.
