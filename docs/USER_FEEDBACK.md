# 홀덤 게임 사용자 피드백 정리

작성일: 2026-10-20
목적: 친구끼리 비공개 방에서 즐기는 무료 가상칩 홀덤 앱의 제품 의사결정 참고.

> **증거 수준 주의:** 아래 내용은 공개 리뷰·커뮤니티 의견에 기반한 정성적 요약과 제품 가설이다. 전체 리뷰의 빈도 통계가 아니며, '조작', '봇' 등은 이용자 의혹이지 사실 확인이 아니다. Codex는 이 문서를 사용자 요구 가설로 다루고 코드 구현 여부를 별도로 확인할 것.

## 긍정 반응 (기능 아이디어)

| 테마 | 이용자가 선호하는 경험 | 제품 적용 가설 |
| --- | --- | --- |
| 친구 전용 테이블 | 모르는 사람 없이 친구들과 함께 플레이 | 초대 코드/링크, 비공개 방 |
| 간편한 접근 | 복잡한 설정 없이 빠른 입장, PC·모바일 접근 | 빠른 온보딩, 다양한 화면 크기 |
| 유연한 홈게임 운영 | 방장이 칩·게임 조건을 조절 | 블라인드, 바이인, 리바인 승인 및 수량 설정 |
| 소셜 경험 | 친구들과 대화하고 함께 노는 분위기 | 리액션, 추후 음성 기능 검토 |
| 게임의 연속성 | 친구들과 다음 모임까지 기록 유지 | 경기 로그, 전적, 친구 간 상대 승률 |
| 빠른 진행 | 불필요한 대기 최소화 | 턴 타이머 설정, 안전한 자동 행동 |

## 부정 반응 (회피할 UX)

| 테마 | 이용자 불만 또는 우려 | 방지 방향 |
| --- | --- | --- |
| 잦은 전면광고·팝업 | 게임 흐름 중단, 과도한 상업화 | 핸드 도중 강제광고 금지, 빈도 제한 |
| 카드 조작 의혹 | 게임 공정성 불신 | 검증 가능한 난수·셔플, 핸드 로그, 결과 테스트 |
| 봇 의혹 | 실제 친구와 게임 중인지 불명확 | 초대 기반 방, 참여자 식별 |
| 칩 구매 압박 | 게임보다 과금이 우선이라는 인식 | 무료 가상칩 원칙, 결제 압박 회피 |
| 연결 끊김 | 진행 상황/칩 손실 불안 | 재접속, 서버 권위 상태 복원, 중복 액션 방지 |
| 게임 판정 오류 | 승패 및 칩 분배 신뢰 붕괴 | 핸드 랭킹, 타이, 올인, 사이드팟 자동 테스트 |
| 긴 턴 대기 | 소셜 게임의 템포 저하 | 턴 제한시간 및 자동 체크/폴드 정책 |
| 복잡한 화면 | 테이블 집중도 저하 | 모바일 우선 단순 UI |
| 불편한 홈게임 운영 | 외부 도구를 별도로 사용 | 방 설정, 리바인, 기록의 통합 |

## 참고 대상 및 근거 해석

- Poker Now: 친구 전용 웹 포커, 기기 접근성, 방 운영 관련 사용자 추천 의견.
- Vegas Infinite: 프라이빗 테이블과 소셜/음성 경험 관련 사용자 의견.
- Zynga Poker: 팝업·과금 압박·공정성 관련 부정적 리뷰/의견과 소셜 플레이 관련 긍정적 회상.
- Governor of Poker 3: 과도한 프로모션, 공정성 의혹, 게임 중 오류 관련 이용자 의견.
- Poker Night at the Inventory: 캐릭터와 유머가 주는 엔터테인먼트 가치.
- Balatro: 전통적 텍사스 홀덤이 아니므로 직접 비교 근거에서 제외.

## 프로젝트 특화 가설

- '친구와 빠르게 시작하고 안정적으로 끝내는 홈게임'을 핵심 가치로 설정.
- 리바인 승인 후 전면광고는 다른 플레이어를 기다리게 만들 수 있으므로 실험 전 UX 영향 평가.
- 리바인·칩 수량·승패 기록이 실제 서버 상태와 일치해야 함.
- 경기 로그 및 친구 간 전적은 차별화 후보지만, 정확성과 개인정보 최소 수집을 우선.
- 가상칩을 현금으로 교환하거나 현금 정산을 중개하는 기능은 범위에 포함하지 않음. 정책·법률 검토 없이 도박성 기능을 추가하지 말 것.
