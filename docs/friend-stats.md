# 친구와 함께한 홀덤 전적

친구 목록의 전적 버튼에서 함께 참여한 판 수, 각자의 팟 획득 횟수/비율과 순 칩 증감을 비교합니다. 사이드 팟 또는 나눠 가진 팟을 포함해 양수를 받은 경우 팟 획득 1회로 집계합니다. 여러 명이 참여하므로 일대일 승률이 아니며 두 사람의 획득률 합계가 100%일 필요가 없습니다. 칩 증감은 함께한 판에서 각자의 전체 순 칩 증감이며 두 사람 사이의 칩 이동만 의미하지 않습니다.

결과는 서버가 판을 완전히 끝낸 후 SQLite에 원자적으로 기록합니다. 동일 핸드 ID는 한 번만 기록하며 서버 재시작/리버 공개 중복으로 집계가 늘어나지 않습니다. 참가 당시 계정 ID를 보존하므로 중간에 나간 플레이어도 포함합니다. 대기실 관전자와 늦게 들어와 패를 받지 않은 플레이어는 제외합니다. 과거 익명 플레이는 계정과 연결할 근거가 없어 소급 집계하지 않습니다.

게임 서버와 함께 STATS_DB_PATH 파일을 영구 볼륨에 저장하고 백업하세요. 기본은 STATE_DB_PATH와 같은 폴더의 stats.sqlite 또는 ./data/stats.sqlite입니다. 한 서버/한 볼륨으로 운영하는 현재 구조의 누적 기록입니다. 서버 이동 시 통계 파일도 이전해야 합니다. 각 기기에서 같은 게임 서버 주소를 사용해야 같은 기록을 봅니다.

GET /friends/{friend UUID}/stats는 현재 유효한 Supabase 로그인과 수락된 친구 관계를 각각 확인합니다. 본인과 지정 친구가 함께한 숫자만 반환하며 카드, 이메일, 타인 전적은 포함하지 않습니다. 친구 관계 해제 즉시 조회가 거부됩니다. 클라이언트 기록 업로드 기능은 없으며 앱에서 승률을 조작할 수 없습니다.

새 Supabase SQL이나 비밀 키는 필요하지 않습니다. 이전 단계 003_single_session.sql은 적용되어 있어야 합니다. 서버 재시작 후 서로 다른 Google 계정으로 로그인하고 친구가 되어 홀덤 한 판을 끝낸 뒤 홈 > 친구 > 전적으로 확인하세요. 아직 끝난 판이 없으면 0판, 서버 연결 오류는 오류 화면으로 구별합니다.
