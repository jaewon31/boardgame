# PWA 실기기 승인 체크리스트

작성일 2026-11-15. **아래 실기기 항목은 모두 미검증이며 체크를 채우지 않았다.** 데스크톱 Chrome viewport 테스트를 iPhone/Android 실기 검증으로 대체하지 않는다.

## 사전 준비

- [ ] 승인된 테스트 HTTPS URL / WSS 서버, 유효 공인 인증서와 정확한 Origin 목록을 준비한다. 테스트 계정만 사용한다.
- [ ] 기기 모델, OS/브라우저 버전, 화면 크기, Safari 또는 standalone 실행 여부, 빌드 revision, 서버 RECONNECT_MS를 기록한다.
- [ ] 별도 기기/브라우저 세션 A·B를 준비한다. 같은 익명 세션을 공유하지 않는다. 친구 코드와 방 코드는 테스트용만 기록하고 토큰·비공개 상대 패는 캡처하지 않는다.
- [ ] 서버 기본 보존 시간을 확인한다: **좌석 180000ms(3분), 방 참여 300000ms(5분, `RECONNECT_MS`)**. 테스트 중 서버 시간과 disconnect 감지 시각을 기준으로 측정한다(2026-11-25 갱신, `feature/seat-management`).
- [ ] 좌석·재접속·리바이 실사용 시나리오(2인·4인·6인)는 [좌석 실사용 테스트 체크리스트](seat-playtest-checklist.md)를 따른다.

## 설치/실행 환경별 확인

| 환경 | 설치 방법 / 확인 | 상태 |
| --- | --- | --- |
| iPhone Safari | HTTPS URL 접속, 공유 → 홈 화면에 추가. OS에 `웹 앱으로 열기`가 있으면 활성화 | 미검증 |
| iPhone 홈 화면 | 아이콘에서 실행, Friends Table 이름/아이콘, 브라우저 주소창 없이 standalone, 상하 safe area 확인 | 미검증 |
| Android Chrome | HTTPS URL에서 메뉴 → 앱 설치/홈 화면 추가. 메뉴 명칭은 버전별 확인 | 미검증 |
| Android 홈 화면 | 아이콘에서 실행, standalone 및 시스템 뒤로가기/최근 앱 복귀 확인 | 미검증 |
| PC Chrome / Edge | 주소창 설치 아이콘 또는 앱 설치 메뉴, 별도 앱 창으로 실행/종료/재실행 | 실제 설치 미검증 |

iPhone 절차 근거: [Apple 홈 화면 웹 앱 안내](https://support.apple.com/guide/iphone/bookmark-a-website-iph42ab2f3a7/27/ios/27). 설치 가능성은 manifest 구성만으로 판정하지 않는다. [MDN 설치 조건](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

설치 버튼이 안 보이면 먼저 HTTPS 인증서, manifest 200/MIME/파싱, 192·512 아이콘 응답, scope/start_url, 브라우저 메뉴를 확인한다. 개발자 도구의 인증서 예외나 강제 설치 플래그를 일반 사용자 설치 성공으로 기록하지 않는다. Apple Developer 계정이나 앱스토어 업로드는 웹 홈 화면 설치 과정에 필요하지 않다.

## 모든 환경에서 반복할 시나리오

| 검증 | 절차와 기대 결과 | 결과 |
| --- | --- | --- |
| 익명 로그인/닉네임 | 첫 접속 → 닉네임 저장 → 홈. reload와 재실행 후 동일 친구 코드 유지 | 미검증 |
| 방 생성/입장 | A 방 생성, B 코드 입장. 최대 6명, 중복 좌석 없음 | 미검증 |
| 초대 링크 | 미인증 B가 `/join/<code>` 접속 → 닉네임 설정 → 해당 방 입장. URL에 토큰 없음 | 미검증 |
| 잘못된 초대 | 잘못된/폐쇄된 방 링크에서 명확한 실패 안내, 다른 방 자동 생성 없음 | 미검증 |
| 멀티플레이 | 시작 → Call/Check/Raise/Fold/All-in → 팟·칩·보드·결과 일치. 상대 패는 공개 전 비노출 | 미검증 |
| 화면 회전 | 세로↔가로, 6인 좌석/카드/팟/버튼 접근. 잘림·의도치 않은 액션 없음 | 미검증 |
| Safari 주소창 | 주소창 펼침/접힘 후 테이블과 액션이 가시 영역에 유지 | 미검증 |
| 키보드 | 닉네임·입장 코드·베팅 금액 입력 중 저장/취소 버튼 접근, 확대/스크롤 문제 없음 | 미검증 |
| 탭 전환 | 다른 탭 30초 후 복귀, 서버 최신 차례/칩으로 동기화, 중복 액션 없음 | 미검증 |
| 잠금 복귀 | 게임 중 화면 잠금 30초·2분 후 복귀. 연결 중에는 액션 비활성, 최신 상태 복구 | 미검증 |
| 네트워크 전환 | Wi-Fi↔셀룰러, 비행기 모드 30초 후 해제. 재연결·개인 패 보호 확인 | 미검증 |
| 게임 중 reload | 본인 패·칩·보드·hand ID 기록 후 reload. 동일한 자격의 기존 방에 복귀 | 미검증 |
| 앱 종료 후 재접속 | standalone 완전 종료 후 1분 내 아이콘 실행. 인증 세션/참여 복구 | 미검증 |
| 3분·5분 경계 | 별도 핸드에서 2분·4분·5분+30초 단절. 3분 안에는 기존 좌석·칩, 3~5분에는 좌석 해제(핸드 종료 후)·칩 유지·관전자, 5분 뒤에는 방 참여 종료(같은 계정 재입장 시 칩 1회 복구). 임의 상태 부활 없음 | 미검증 |
| 같은 계정 중복 연결 | 동일 계정 새 탭·다른 기기 연결 시 기존 연결 종료(4003) 안내, 새 쪽이 같은 좌석·칩을 이어받음. 양쪽에서 무한 재접속 경쟁 없음 | 미검증 |
| 세션 만료 | 승인된 개발 환경에서 인증 만료/refresh 실패를 재현. 실패 안내 후 권한 없이 방에 진입하지 못함 | 미검증 |
| 저장소 제한 | 시크릿·저장소 차단·테스트 데이터 삭제 후 익명 계정 복구 제한 안내. 기존 계정 자동 복구를 약속하지 않음 | 미검증 |
| 브라우저↔PWA | 설치 전후 친구 코드를 비교. 저장소가 분리되면 새 익명 계정으로 취급하며 기존 계정 복구 성공으로 기록하지 않음 | 미검증 |
| 오프라인 실행 | 온라인 게임 불가가 명확하고 기존 화면에서 액션이 서버 성공으로 오인되지 않음. SW 없으므로 첫 로드 자체가 실패할 수 있음 | 미검증 |
| 새 버전/서버 재시작 | 게임 없는 유지보수 시각에 승인된 스테이징에서만 재시작. SQLite 복구/재접속/최신 웹 파일 확인 | 미검증 |
| 혼합 플레이 | Android 네이티브 + iPhone/PC 웹 동일 방 진행·복귀 | 미검증 |

잠금·단절 동안 서버는 턴 timeout을 처리할 수 있다. 복귀 시 과거 액션 버튼/패를 그대로 재현하는 것이 아니라 **서버 현재 상태와 일치하는지** 판정한다. 본인 패가 같아야 하는 비교는 같은 hand ID에서만 한다. 결과를 기록할 때 중단 시각·복귀 시각·hand ID·서버 차례만 남기고 인증 토큰은 수집하지 않는다.

## 결과 기록 양식

`기기 / OS / 브라우저 / 실행 모드 / 빌드 / 시나리오 / 통과·실패·미검증 / 관찰 / 증거 파일`

실패를 찾으면 반복 조건과 스크린샷을 기록하고 공개 공유 전에 수정·재검증한다. 실제 기기에서 검증하지 않은 현재 상태로 PWA 설치/장시간 연결/잠금 복귀를 완료 표시하지 않는다.
