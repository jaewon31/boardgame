# 모바일 홀덤 UI 검토 — 2026-10-11

## 참고 자료
- [PokerStars 공식 모바일 다운로드 화면](https://www.pokerstars.com/download/): 공식 홍보 이미지에서 중앙 보드, 주변 좌석, 하단 Fold/Call/Raise 및 베팅 프리셋의 배치를 확인했다. 홍보 화면이며 설치된 최신 앱을 직접 실행한 검토는 아니다.
- [PokerStars 세로 테이블 소개](https://www.pokerstars.uk/poker/learn/news/mobile-portrait-tables-now-available-on-pokerstars/): 2021년 자료. 한 손으로 조작하는 세로 배치의 참고 사례로 사용했다.
- [GGPoker Card Squeeze](https://ggpoker.com/poker-games/table-social-features/): 실제 카드처럼 확인하는 squeeze와 즉시 공개 버튼, 올인 중 보드 squeeze를 설명한다. 이 프로젝트의 턴 열세 플레이어 선정 규칙은 별도 사용자 요구사항이다.

## 현재 화면의 문제와 반영
1. 공용 카드가 좌석 박스에 비해 너무 작았다. 보드를 최대 44dp로 확대하고 팟 표시는 한 줄로 줄였다.
2. 각 좌석 전체가 큰 정보 패널처럼 보였다. 이름/스택만 작은 명패로 묶고 카드와 상태를 테이블 위에 분리했다.
3. 폴드/콜/레이즈/올인 두 줄이 테이블 높이를 차지했다. 하단 세 버튼으로 정리하고 올인은 베팅 창에서 선택한다. 폴드 회색, 체크/콜 녹색, 베팅 적색으로 구별한다.
4. 과한 영문 브랜드와 갈색 테두리를 줄이고 어두운 레일/초록 펠트로 대비를 정리했다.
5. 카드 앞면이 사각형/삼각형 구멍을 통해 나타나던 째기를 교체했다. 들어 올린 뒷면 영역을 제거하고 접힌 앞면을 새로운 위치에 그려 카드 윤곽이 따라 움직이게 했다. 접힘 음영, 겹침 그림자, 밝은 단면을 추가했다. 글자는 거울상이 되지 않게 회전한다.

## 검증 범위와 한계
Android 에뮬레이터에서 상단/대각선 드래그의 중간 상태, 손을 놓았을 때 복귀, 360×640 크기의 6인 화면과 베팅 창을 확인했다. 카드 표현은 SVG 기반 2D 접힘 근사이며 3D 물리 시뮬레이션이 아니다. iOS 실제 기기에서의 촉감/성능 검증은 별도로 필요하다. 참고 앱의 이미지나 로고를 앱 자산으로 복사하지 않았다.
