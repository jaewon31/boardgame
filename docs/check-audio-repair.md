# CHECK 효과음 깨짐 조사·수정

2026-11-10 KST. 기준 커밋: 9e741b27c305b6ec11eb463b6d8677e6690c555f.

## 확인된 원인

`check-user.wav`의 이전 정규화 과정(+2.8659668 dB 증폭 후 1ms attack/10ms release limiter)이 두 타격의 앞부분에 원본에 없던 급격한 파형 불연속을 만들었다. 기록된 필터를 원본 `table_knock_check.mp3`에 다시 적용한 결과, 현재 배포 소스 WAV와 SHA-256이 완전히 일치했다(`e0ceda…f3c0`). 따라서 이 파형 결함은 재생 장치에서 추정한 현상이 아니라 파일 생성 단계에서 재현한 결함이다.

기존 WAV의 최대 인접 샘플 변화량은 0.674713으로 원본의 0.026476보다 약 25.5배 컸고, 최대 변화는 약 43.27ms에서 발생했다. 4kHz high-pass 출력 RMS도 원본 −75.09 → 기존 −47.86 dBFS로 증가했다. 이는 단순한 선형 볼륨 증가로 설명되지 않는 고주파 성분 증가다. 파형을 원본/기존/수정본으로 비교했다. 이전 검사에서 sample/true peak가 0 dBFS 미만인 것만으로는 이 종류의 왜곡을 검출하지 못했다.

원본은 48kHz mono, 약 40kbps MP3이며 두 타격과 감쇠 잔향을 포함한다. 원본의 포화 샘플은 0개이고 두 타격 사이 220–240ms 및 500ms 이후는 디코딩된 샘플이 0이다. 지속적인 배경 잡음이 원인이라는 증거는 없어 과도한 노이즈 제거, EQ, 새 음원 합성을 하지 않았다. 원본의 고유한 저음 잔향을 유지했다. 저비트레이트 MP3의 모든 지각적 아티팩트가 없다는 의미는 아니다.

## 재생 경로 점검

- CHECK는 `useGameAudio.ts`의 단일 `check-user.wav` 플레이어를 사용한다. CALL은 `bet-user.wav`이며 그대로 유지했다. 다른 파일 폴백이나 이중 CHECK 플레이어는 없다.
- 실제 게임 이벤트는 핸드/리비전/사운드 ID로 중복 방지한다. 같은 스냅샷 반복은 한 번만 재생하며, 서로 다른 연속 CHECK는 진행 중 음원을 자르지 않고 다음 재생을 기다린다.
- STATE_ENDED에서 currentStatus.isLoaded로 재사용하는 기존 Android 오류 수정과 seek 잠금/취소 처리를 유지했다. 추가 테스트에서 같은 CHECK 플레이어의 두 번째 재생과 중복 방지를 확인했다.
- 미리듣기와 게임은 같은 플레이어·음원·gain 계산을 사용한다. 차이는 기존 정책대로 미리듣기는 마지막 선택 우선 취소, 실제 게임은 순서대로 완료 후 재생이다. 빠른 CHECK 미리듣기에서 오래된 seek가 뒤늦게 이중 재생하지 않는지 테스트했다. 명시적으로 미리듣기를 빠르게 다시 누르면 앞 소리가 중단될 수 있으며, 이 동작을 파일 자체 왜곡과 혼동하지 않았다.
- 이번 조사에서 재생 큐/중복/플레이어 재사용의 새 결함은 재현되지 않았다. 이들 제품 코드는 변경하지 않았다. 사용자가 청취한 실제 APK의 스피커 출력을 녹음해 원인을 단독 확정한 것은 아니며, 파일 단계에서 재현된 결함을 제거한 것이다.

## 수정 및 측정

원본 MP3에서 다시 디코딩하고 mono PCM16/44.1kHz로 저장했다. 처리 필터는 `aformat=channel_layouts=mono,aresample=44100,volume=-2.5526183636528636dB`뿐이다. 리미터/컴프레서/비선형 정규화를 제거했다. 타격은 40ms와 280ms에 시작하고 전체 길이 720ms, 간격과 감쇠를 유지한다.

수정본은 선형 감쇠한 원본과 최대 오차 0.000015272로 PCM16 반올림 범위 이내에서 일치한다. CHECK RMS는 이전보다 약 2.44 dB 낮아졌으며 피크는 동일하다. CHECK/CALL 매핑, CHECK 기본 gain, 마스터·개별 gain·출력 상한, 음소거·저장 설정, 다른 효과음 파일과 재생 코드는 변경하지 않았다.

## 검증 및 범위

- 파형 회귀 테스트를 수정 전 파일에서 먼저 실행해 0.674713 불연속으로 실패하는 것을 확인했고, 수정 후 통과했다.
